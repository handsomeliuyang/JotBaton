Remarc's global shortcuts default to `Ctrl+Option` plus a letter. Rebind any of them in Settings > Shortcuts, which warns you when a new binding conflicts with another Remarc shortcut.

## Global shortcuts

Global shortcuts work in any app while Remarc is running.

| Action | Shortcut |
| --- | --- |
| Open Remarc | `Ctrl+Option+R` |
| Comment on selection | `Ctrl+Option+C` |
| Quick Note | `Ctrl+Option+N` |
| Screenshot | `Ctrl+Option+S` |
| Screenshot & Send Instantly | Unassigned |
| Paste All (copy all comments) | `Ctrl+Option+P` |

**Screenshot & Send Instantly** ships unassigned. Its row appears in Settings > Shortcuts only after you enable **Allow comments to wake paired agent sessions** in Settings > MCP Integrations.

**Quick Note** opens a standalone note even when text is selected. Repeating it brings the open editor forward and preserves its draft. The development app uses `Ctrl+Option+Shift+N` by default.

## Comment composer

The comment composer responds to two keys of its own.

| Action | Shortcut |
| --- | --- |
| Save the comment | `Cmd+Return` |
| Cancel and close | `Escape` |

## Chrome extension

The [Chrome extension](/chrome-extension/)'s capture shortcuts work inside the browser and can be changed in Settings > Chrome Extension or Settings > Shortcuts.

| Action | Shortcut |
| --- | --- |
| Grab Element | `Option+Shift+G` |
| Select Region | `Option+Shift+R` |

Chrome only accepts `Ctrl+Shift` or `Option+Shift` combinations; `Cmd` is not supported.
